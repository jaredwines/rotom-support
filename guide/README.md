# Supplementary Guides

**Artifact class:** Supplementary repository guide; not a Rotom Support or Available Sources member

This directory contains repository guides that are deliberately separate from Rotom Support, the Core Numbered Reference Set, Available Sources, RS-only validation, and RS publication. They may explain or orchestrate material owned by the numbered runbooks, but they do not become authoritative fact owners.

- [PVE and Rotom Total-Loss Recovery](PVE-and-Rotom-Total-Loss-Recovery.md) coordinates blank-hardware disaster recovery across the authoritative subject runbooks. It is also published in the private repository mirror.
