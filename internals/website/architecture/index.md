# Rotom Architecture

Rotom Architecture describes how Rotom's infrastructure, applications, network, storage, and data protection fit together. It provides a high-level map of the system and the relationships between its services and supporting systems.

For a detailed overview, see [Rotom Architecture System](rotom-architecture-system.md). The [Runbook](../runbook/index.md) is the authoritative source for current configuration and operational procedures.
