# Website Inputs

This directory contains selected supplementary Markdown inputs for the private Rotom Support portal plus navigation READMEs. It is a source/input tree, not generated or deployed website output.

## Inputs

- [`home.md`](home.md) is the portal landing page.
- [`architecture/`](architecture/README.md) contains the supplementary architecture page.
- [`guides/`](guides/README.md) contains the supplementary task-routing page.

The repository publication source set combines these selected inputs with the approved numbered runbooks and two explicitly approved canonical supplementary documents: `architecture/Rotom-Architecture-System.md` and `guide/PVE-and-Rotom-Total-Loss-Recovery.md`. Publication does not make the supplementary pages Rotom Support members or Available Sources. The installed publisher still expects the architecture document's prior filename until a separately authorized live publisher update; generated site output and the live deployment are maintained outside this directory, so edit the canonical repository inputs rather than generated files.

The README files in this tree are repository navigation only and are not approved publication inputs.

The publication workflow is owned by [06 — Maintenance and Automation](../../runbook/06-Maintenance-and-Automation.md), while authority and membership are defined by [01 — Rotom Server Inventory](../../runbook/01-Rotom-Server-Inventory.md#7-rotom-support-model). Run the repository validations described in [`internals/tooling/`](../tooling/README.md) after changes.
