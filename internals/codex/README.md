# Rotom Codex Internals Overview

This directory stores agent-facing support material for working on Rotom.

- [`rotom-global-AGENTS.md`](rotom-global-AGENTS.md) is a repository backup of the active global Codex instructions. Its opening note defines the synchronization expectation; the active file remains outside this repository.

This tracked material is an agent-support RS component, not an authoritative runbook. Operational facts and procedures must link to their numbered owner in [`runbook/`](../../runbook/README.md). When the active global instructions are intentionally changed, review this backup for the corresponding update and follow the root [`AGENTS.md`](../../AGENTS.md) plus the [RS maintenance contract](../../runbook/00-Rotom-Change-Log.md#current-documentation-maintenance-rules) if RS behavior or ownership changes. Available Sources is a separate manually maintained destination.
