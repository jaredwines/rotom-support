# Repository Internals

This directory contains material that supports work on and publication of the repository. It is not itself an operational runbook collection, and its files are not Rotom Support members or Available Sources merely because they are tracked here.

## Areas

- [`codex/`](codex/README.md) stores agent-support reference material.
- [`tooling/`](tooling/README.md) provides the guarded repository helper and validation scripts.
- [`website/`](website/README.md) contains selected source inputs for the private documentation portal.

Use the root [repository instructions](../AGENTS.md) before changing internal repository material. If an internal change alters an RS-owned procedure, fact, publication contract, or source map, also follow the [canonical maintenance contract](../runbook/00-Rotom-Change-Log.md#current-documentation-maintenance-rules). Validate the affected area with the scripts described in the tooling README.
